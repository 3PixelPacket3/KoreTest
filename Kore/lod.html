Reference: Applied Logic Rules

Core Identifiers

  • Group Code: All caps (e.g., SAMS).
  • Customer Number: Numeric; cannot end in 00.
  • Quantity: Numeric, > 0.
  • Order Type: GO, GR, PA, or DO (unless bypassed).
  • Allocation Rule: Strictly O.

PA & PALOD Strict Logic

  • LOD: If Order Type is PA, PO must start with 1NAPR-.
  • PALOD: ALL rows require PO to start with 1NAPR-.
  • Uniqueness: Customer PO must be different for each order, but the same for one order consolidated by location.
  • Item Duplication: Multiple lines on the same Customer PO cannot share the exact same Item Number.

Data Quality & Logistics

  • Whitespace & Artifacts: Cells containing leading/trailing spaces or backticks (`) are flagged (unless bypassed).
  • State/Country: 2-char uppercase (NY, US).
  • ZIP: 4, 5, 8, or 9 digits (accommodating zero cut-off).
  • Service Level: ALL CAPS exactly: BEST, NEXT, 2DAY, 3DAY, MAIL, GND, ITG, ITGF, ATLAS, NDS, TTI, STORU, UPS, or PCL.

Communications

  • Phone: Exactly 10 digits (no spaces/hyphens).
  • Emails: Splits multiple addresses by semicolon (;). Strictly blocks international/invalid domains (e.g., .ora, .uk). Restricts TLDs to standard US/Enterprise (.com, .org, .net, .edu, .gov, .mil, etc.).
  • Site: Required when using either confirmation email.
